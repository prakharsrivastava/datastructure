The G-Measure (or G-Mean) is an alternative to the F1-score. Instead of the harmonic mean, it takes the geometric mean of Precision and Recall.

//Imbalanced datasets
G= sqRoot(Precision×Recall)


Final Verdict: Which Detective is Better?
If we want to be 100% sure before arresting, ACP Pradyuman wins (High Precision).
If we don’t want any criminal to escape, Singham wins (High Recall).
If we need a balance, both have the same F1-Score (72%)!
🔹 Lesson: The best metric depends on the use case!

✅ Use F1-Score for balanced decisions
✅ Use G-Measure for imbalanced data
✅ Use Precision when False Positives are costly
✅ Use Recall when False Negatives are costly
